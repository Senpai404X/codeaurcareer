## Kyun Freelancing?

College ke saath freelancing karna ek smart move hai:

- **Real projects** portfolio mein jaate hain
- **Income** part-time, flexible hours mein
- **Experience** degree se zyada interviews mein help karti hai

Lekin bina plan ke shuru karoge toh 2 mahine baad give up kar doge. Ye roadmap follow karo.

## Step 1: Ek Skill, Ek Niche

Sab kuch mat karo. Ek cheez mein expert bano:

| Skill Level | Service You Can Offer |
|-------------|----------------------|
| Beginner | WordPress landing pages, basic HTML/CSS sites |
| Intermediate | React landing pages, bug fixes, API integration |
| Advanced | Full-stack apps, mobile apps, automation scripts |

**Recommendation for students:** React landing pages ya WordPress sites — demand high hai, entry barrier low.

## Step 2: Portfolio Banao (Clients Se Pehle)

2-3 demo projects banao — real client ki zarurat nahi:

1. Restaurant landing page
2. Portfolio website for a fictional developer
3. Simple dashboard UI

Inhe **live deploy** karo (Vercel free hai). Link share karna easy ho.

## Step 3: Platform Choose Karo

### Fiverr (Best for Beginners)
- Gigs create karo: "I will build a responsive React landing page"
- Start price: ₹1500–3000
- Pehle 5 reviews ke liye thoda sasta rakho

### Upwork
- Long-term clients milte hain
- Profile strong honi chahiye — Fiverr se reviews leke aao

### Internshala / LinkedIn
- Indian clients, direct communication
- "Open to freelance projects" likho profile mein

## Step 4: Pehla Client Kaise Mile

1. **Network** — college seniors, local businesses, family friends
2. **Cold outreach** — 10 small businesses ko WhatsApp/email: "Main student developer hoon, aapki website improve kar sakta hoon"
3. **Underprice initially** — pehla project ₹1000–2000 mein bhi lo, review/referral ke liye

> **Reality:** Pehla client sabse mushkil hai. 20 logon ko message karo, 1 reply aayega — ye normal hai.

## Pricing Guide (India, 2026)

| Service | Beginner Rate |
|---------|---------------|
| Landing page | ₹2,000 – 5,000 |
| Bug fix (small) | ₹500 – 1,500 |
| WordPress site | ₹3,000 – 8,000 |
| React component | ₹1,000 – 3,000 |

## Common Mistakes

- ❌ Bina contract/agreement ke kaam karna
- ❌ 50% advance lena bhool jaana
- ❌ Scope creep — "ek chhoti si change" × 20
- ❌ Portfolio ke bina Fiverr pe wait karna

## Conclusion

Pehla ₹5000 kamana possible hai 1-2 mahine mein agar tum consistently outreach karo aur deliver karo. Skills + communication dono matter karte hain. Start small, reviews collect karo, price badhao.
